# Landing Page - Oasis Infobyte (OIBSIP)

## Task Description
This repository contains the source code for the Level 1 Web Development task: **Landing Page**. 
The objective of this task is to build a visually polished static landing page for a product, service, or brand using HTML5 and CSS3 (without JavaScript).

## Features
- **Responsive Layout:** Adapts flawlessly to mobile and desktop screens using CSS Flexbox and Grid.
- **Sticky Navigation Bar:** Easy access to different sections.
- **Hero Section:** Features a catchy headline, subheadline, and Call-To-Action (CTA) buttons.
- **Content Sections:** Includes a distinct "Features" section and a "Testimonials" section.
- **Custom Styling:** Clean and consistent color palette (Blue/Slate) and typography (Inter font).
- **Zero JavaScript:** Built entirely using HTML5 and CSS3.

## Tech Stack
- HTML5
- CSS3 (Flexbox & Grid)

## How to Run
1. Clone or download this repository.
2. Open `index.html` in any modern web browser to view the landing page.
