# Personal Portfolio - Oasis Infobyte (OIBSIP)

## Task Description
This repository contains the source code for the Level 2 Web Development task: **Personal Portfolio Website**. 
The objective of this task is to create a personal portfolio website that showcases skills, projects, and contact information — effectively functioning as a digital résumé.

## Features Checklist
- [x] **Profile / Hero Section:** Name, professional role title, and avatar placeholder.
- [x] **About Me Section:** Background summary, design philosophy, and quick stats.
- [x] **Skills Section:** Visual grid of technical proficiencies (HTML5, CSS3, Flexbox/Grid, Responsive Design, JavaScript, Git/GitHub).
- [x] **Projects Section:** Multiple featured project cards with live demo and GitHub repository links.
- [x] **Contact Section:** Direct contact channels (Email, Location, Profiles) and a demonstration contact form.
- [x] **Smooth Scroll Navigation:** Sticky header with seamless jumping between sections.
- [x] **Consistent Branding:** Modern dark palette with indigo/cyan highlights and Space Grotesk & Plus Jakarta Sans typography.
- [x] **Fully Responsive:** Fluid layouts designed for mobile, tablet, and desktop screens.

## Tech Stack
- HTML5 (Semantic elements)
- CSS3 (Custom Variables, Flexbox, CSS Grid, Glassmorphism, Transitions)
